# LeakHalo Privacy Policy

Last updated: 2026-11-03

LeakHalo checks your public IPv4 and IPv6 addresses and approximate IP location. While the popup is open it checks IP addresses about every three seconds (every ten while Instant change detection is on); background checks are scheduled about every 30 seconds when enabled. The extension sends HTTPS requests to Cloudflare, icanhazip, ipify, and Amazon Check IP for IP discovery, and to ipwho.is, GeoJS, or ipinfo.io for location and network metadata. Those providers receive your public IP address and normal request metadata under their own policies. When none of these providers answers, LeakHalo sends a simple request to Cloudflare, ipify and Amazon Check IP to tell a lost connection from a provider problem. LeakHalo does not send browsing history, page content, or analytics to its developer.

**Instant change detection (on by default).** To notice a changed IP within seconds even when the popup is closed, the extension checks your IP with Cloudflare every ~3 seconds while you are actively using the computer. These checks pause when the computer is idle or locked. The extension uses Cloudflare's trace endpoint only as a signal to notice when your IP or country changes, and then verifies it with the regular providers. You can turn this off in Settings under Monitoring ("Instant change detection"); it is also off whenever automatic background checks are off.

The extension stores your latest IP and location results, settings, last check time, notification cooldown, and temporary provider rate-limit cooldowns in Chromium's local extension storage. It uses this data to show the popup, update the toolbar icon, and optionally alert you when your IP changes. It keeps no history of IP addresses: besides the latest result it keeps only the previous address of each kind, needed to report a change, and the latest address seen for a different route. A short-lived location cache, kept in memory only while the browser runs, can reuse results when you switch back to a recently used IP. You can remove the stored IP data at any time with "Clear data" in Settings, and all local data by uninstalling the extension.

When enabled, the shield changes Chromium's WebRTC IP handling policy through the browser `privacy` API. A separate setting can disable Chromium's network prediction. You can turn these features off in the popup or Settings. The WebRTC diagnostic may contact Google's STUN server at `stun.l.google.com:19302` while the popup is open and the shield is off or set to Balanced. That server can see your public IP and normal request metadata.

Location names in the popup can link to OpenStreetMap; opening one sends the approximate coordinates in the link to openstreetmap.org. The "More leak tests" links in Settings open independent sites. LeakHalo sends nothing to these sites; they see what any website you open sees. Map links can be turned off in Settings.

When you remove the extension, Chrome opens a short page on LeakHalo's website (`slmn-labs.github.io`) asking why. It receives only the extension version and your browser language. If you tap a reason or write a comment, that answer, with the version and language, is stored in a Google Form owned by the developer; nothing else about you is sent. You can simply close the page.

LeakHalo has no user account, advertising, or analytics, and runs no server of its own. Contact: slmn.labs.official@gmail.com

# IP provider review (2026-09-29)

LeakHalo sends users' public IP addresses directly from their browsers. The code requests one primary IPv4 discovery source and one IPv6 source, with sequential fallbacks. While the popup is visible it checks about every three seconds without overlapping requests. Every IPv4 check (popup and background alike) asks two independent vantage points in parallel: Cloudflare's trace endpoint (falling back to icanhazip, which Cloudflare operates) and ipify (falling back to Amazon Check IP). The displayed IP always comes from the Cloudflare group. If both groups keep answering with different IPs for at least 15 seconds, the extension records that sites see different IPs (typical of a proxy, a split-tunnel VPN or provider routing that sends only some destinations through another public IP). It always shows the main IP and country; the popup card, toolbar marker and notification for this case appear only if the user turns on "Warn when sites see different IPs" in Settings (off by default). Background checks are scheduled about every 30 seconds. Geolocation is requested when an IP changes, with a 16-entry, 30-minute in-memory cache for recently revisited IPs. Missing metadata is retried no more than once per 15 minutes, and repeated manual geolocation refreshes of the same IP are limited to once per five minutes. An HTTP 429 response suspends requests to that provider for at least five minutes or the longer Retry-After duration, up to 24 hours.

| Service | Use | Official source and finding |
| --- | --- | --- |
| Cloudflare trace, icanhazip, ipify, Amazon Check IP | Discover public IP | [ipify's official site](https://www.ipify.org/) says its public IP API has no request limit. Cloudflare trace and ipify are both queried on every check (two requests per popup tick). The other endpoints remain fallbacks and their availability and acceptable use should be monitored after release. |
| ipwho.is | First geolocation lookup | [Documentation](https://ipwhois.io/documentation): free endpoint permits commercial use and has a 1,000 request/day limit per client IP; no uptime guarantee. |
| GeoJS | First geolocation fallback | [General documentation](https://www.geojs.io/docs/general/): no current rate limit. [Geo endpoint](https://www.geojs.io/docs/v1/endpoints/geo/) includes country, location, ASN and organization fields. |
| IPinfo legacy public API | Last geolocation fallback | [IPinfo support](https://support.ipinfo.io/hc/en-us/articles/34121895556242-Legacy-Free-API-vs-IPinfo-Lite): unauthenticated endpoint is limited to 1,000 requests/day. [Support FAQ](https://support.ipinfo.io/hc/en-us/articles/30792479436562-What-Is-the-Difference-Between-Using-the-Authenticated-Free-Plan-and-the-Public-API-With-No-Account) says the limit is shared by clients on the same public IP. |

The former `ipapi.co` fallback was removed: its [pricing page](https://ipapi.co/pricing/) describes free access as trial and development use, not production deployment.

These providers are independent third parties. They may change limits, availability, policies, or response schemas. The extension retains the last good result and marks verification as failed when all discovery sources fail.
